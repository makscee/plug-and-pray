# thaw

A terminal game for Ludum Dare 60, theme "Old Tech".

You are an old machine waking blind inside a dead god's body, an endless machinery of chambers and conduits. You start with a console and nothing else; everything you become is a module you find, print and install, each one a window on the screen. Follow the memory cards to the three shards of scripture, and carry the Thaw Engine to the god's heart.

- Build plan: [PLAN.md](PLAN.md)
- Play: https://makscee.github.io/plug-and-pray/ (the GitHub Pages build of `main`)

## Run

```
npm install
npm run dev
```

`npm run build` makes the production build in `dist/`. `npm test` runs the model tests, `npm run play` types a run headless on seed 1. `npm run package` rebuilds the Ludum Dare submission in `submission/` (the zip, five screenshots, both page texts; see [submission/README.md](submission/README.md)).
